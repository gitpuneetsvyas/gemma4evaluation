## 3.3 Authentication Flow (JWT Based)

1.  **Client Login:** Client sends credentials to the **Auth Service** (via[4D[K
(via API Gateway).
2.  **Token Generation:** Auth Service validates credentials and generates [K
a signed **JWT** containing user ID, roles, and expiration time.
3.  **Token Issuance:** The JWT is returned to the Client.
4.  **API Request:** For every subsequent request, the Client includes the [K
JWT in the `Authorization: Bearer <token>` header.
5.  **Gateway Validation:** The API Gateway intercepts the request, validat[7D[K
validates the JWT signature and expiration time. If valid, it extracts user[4D[K
user context and applies **Authorization Policies** (via Service Mesh).
6.  **Service Mesh Enforcement:** The Service Mesh ensures that only authen[6D[K
authenticated and authorized services can communicate, enforcing **mTLS** b[1D[K
between all microservices.
