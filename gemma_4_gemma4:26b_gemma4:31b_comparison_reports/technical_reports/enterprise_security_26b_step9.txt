## 3. Data Protection & Privacy Framework

To satisfy **GDPR, CCPA, and PCI-DSS**, we implement a **Data-Centric Secur[5D[K
Security** model.

### Data Classification Engine:
Automated scanning of S3 buckets, SQL databases, and Kafka streams using NL[2D[K
NLP to identify PII/PHI/PCI.

### Data Residency & Sovereignty Implementation:
We use **Geo-Sharding** at the database level. 
*   **EU Region:** All data tagged `EU-Resident` is physically stored in Fr[2D[K
Frankfurt/Paris.
*   **US Region:** Data tagged `US-Resident` stays in US-East/West.
*   **Compliance Layer:** A global metadata catalog tracks the "Residency T[1D[K
Tag" of every object.

### Encryption & Tokenization:
*   **At Rest:** AES-256-GCM with hardware-backed keys (HSM).
*   **In Motion:** TLS 1.3 with mandatory certificate pinning.
*   **In Use:** Format Preserving Encryption (FPE) for legacy mainframe sys[3D[K
systems to allow processing without decrypting sensitive fields.
